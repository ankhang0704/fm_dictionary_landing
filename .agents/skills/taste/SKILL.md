# Taste Skill — Framer Dark Futuristic Enforcer

This skill audits frontend code to ensure high visual restraint anchored to `DESIGN.md`:

1. **Canvas Discipline**: Verify backgrounds remain near-black (`#090909`), never light or washed out.
2. **Hairline Precision**: Ensure all card and container dividers use `1px` subtle hairline borders (`#262626`).
3. **Typography Punch**: Large display headings must have tight negative tracking (`tracking-tight` / `-0.04em`).
4. **Primary CTA Dominance**: The primary conversion action is always a crisp, solid white pill (`bg-white text-black rounded-full`) on dark canvas.
5. **Atmospheric Spotlights**: Use soft radial blurs in violet, magenta, and orange behind key elements to create a cinematic feel without visual clutter.
