# SEO & Metadata Audit Skill

Audit checklist for pages:
- Valid `title` and `description` tags on all routes.
- `og:image`, `og:title`, and `twitter:card` configured.
- `robots.ts` and `sitemap.ts` configured for search crawler indexing.
